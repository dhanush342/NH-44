# NH-44 — Open-source technology notes

NH-44 remains a dependency-light browser game. The project uses the existing Three.js/WebGL renderer and the browser Web Audio API rather than mixing multiple full game engines into one runtime.

The following open-source projects were reviewed for architecture, rendering, input, physics, and web-game patterns:

- Three.js — 3D rendering foundation already used by NH-44. MIT licensed.
- Planck.js — Box2D-derived JavaScript/TypeScript 2D physics engine. MIT licensed. Its fixed-step/rigid-body ideas informed the stability of the arcade physics, but Planck.js source is not bundled.
- Phaser — web-game framework; its scene/input/FX patterns informed the new gameplay feedback layer. MIT licensed.
- PlayCanvas Engine — WebGL/WebGPU engine reviewed for browser performance patterns. MIT licensed.
- PixiJS — GPU rendering and UI/FX patterns reviewed; not bundled because NH-44 is already a 3D Three.js application.
- Godot — MIT-licensed 2D/3D engine reviewed for game-state and export considerations; not bundled.
- GDevelop — MIT-licensed open-source game development stack reviewed for challenge/event design; not bundled.
- Excalibur.js — BSD-2-Clause web 2D engine reviewed for TypeScript/game-loop patterns; not bundled.
